# Chellat-News 📰

A modern, fully responsive Arabic-first news portal featuring a slow readable ticker, dynamic categories, and seamless Dark/Light theme switching.

## 🚀 Features
- **RTL-First Architecture:** Optimized natively for Arabic layout and typography (Cairo font).
- **Dark / Light Themes:** Smooth theme toggle via CSS variables.
- **Breaking News Ticker:** Interactive live updates and category filtering.
- **Responsive Design:** Fully adaptive for desktop, tablet, and mobile screens.

## 🛠️ Tech Stack
- **HTML5**
- **CSS3**
- **JavaScript (ES6+)**
